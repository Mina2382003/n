# Image-to-video prompts (for full character acting)

Upload each `stills/rawN.png` to an image-to-video model (Kling 2.x, Runway Gen-4, Google Veo 3, Hailuo, or Wan 2.2),
5 s, 16:9, "camera: slow", then drop the clips in order. Same style line on every prompt keeps the shots consistent:

> Style: 3D animated feature film, Pixar/Disney look, soft cinematic lighting, gentle camera move, no text, no cuts.
